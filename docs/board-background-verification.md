# 보드 배경과 원판 비율 확인

2026-10-20 로컬 프로덕션 빌드 확인

## 변경

보드 배경을 16:9 무대 크기와 화면 전체 크기로 두 번 표시하던 CSS를 제거
서로 다른 축척의 나무·등불·바닥 무늬가 겹치던 원인

기존 배경 한 장을 원래 16:9 비율로 표시하고 원본 바닥 기준점 (917, 630)을 보드 무대의 같은 좌표에 고정
기준점에서 화면 네 끝까지 덮는 최소 크기를 사용하며 창 비율에 따라 바깥 풍경의 보이는 범위가 달라짐
원판·말·주사위·메뉴는 기존 무대와 클릭 좌표를 유지
모바일의 원래 장면 자르기·확대·스크롤 방식은 유지

실제 50% 축소 검수에서 상태판 그림의 샘플 타이머가 드러나는 것도 발견
실제 상태 표시 뒤의 가림 영역을 패널 높이에 비례하게 유지하도록 보완

배경과 원판 WebP 원본의 Git 해시는 변경 전과 동일
새 이미지·글꼴·런타임 JavaScript 의존성을 추가하지 않음
배경 이미지 요청은 전후 모두 한 번이며 두 번 그리던 렌더링을 제거한 변경

## 실제 브라우저 배율

CSS zoom이나 시각적 확대만으로 대신하지 않고 실제 devicePixelRatio 변화도 확인
