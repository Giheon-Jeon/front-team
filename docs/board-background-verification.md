# 보드 배경과 원판 비율 확인

2026-10-20 로컬 프로덕션 빌드 · PR #124

## 배경과 원판

데스크톱과 모바일 모두 기존 배경 한 장을 원래 16:9 비율로 표시
원본 바닥 기준점 (917, 630)을 원판이 놓이는 무대 좌표에 고정하고 화면 네 끝을 덮는 최소 크기로 배경을 계산

모바일 원판은 원본 무대의 x448/y120, 951×960 영역 안에서 배치
상태판 줄바꿈, 창 크기 변경, 확대 보드의 가로 이동으로 원판 위치가 변할 때 바닥 기준점도 갱신
내부 장면의 중복 배경과 경계 마스크를 제거하여 서로 다른 배경 두 장이 보이는 문제를 해소

배경과 원판은 각각 원래 종횡비를 유지
화면 전체를 채우는 배경과 원판의 축척은 다를 수 있으며 바닥의 기준점을 일치시키는 방식

원판 위치는 원본 1920×1080 좌표의 비율로 계산
이미지 자체의 1772×1330 비율을 사용하여 반올림된 높이 비율로 미세하게 늘어나던 문제를 보정
말과 36개 클릭 영역도 같은 원판 좌표계를 사용

## 주사위 상태판

검정 가림 박스를 제거
샘플 숫자와 게이지 영역 전체를 같은 원본 상태판의 빈 목재 영역으로 대체하여 끝부분이 남지 않도록 처리
원래 테두리와 주사위 그림을 유지하고 횟수·충전 시간·안내 문구를 표시

모바일은 원래 나무 재질과 금테를 사용하며 횟수 16px, 충전·제한 시간 14px로 배치
좁은 화면에서는 문구를 줄바꿈
데스크톱 1101×900, 1600×600, 1440×900에서 주사위 소모 후 횟수·충전 문구가 겹치지 않는지 확인

## 검수

`scripts/qa-frontend-live-layout.js`에서 다음 흐름 실행

- 320~3840px 범위에서 새로고침 없이 화면 크기 44회 변경
- 36개 칸의 원본 좌표와 클릭 영역, 말의 시각적 기준점, 주사위 조작 위치 확인
- 주사위 굴림 후 말이 1번에서 6번 칸으로 이동하고 횟수가 3에서 2로 바뀌는지 확인
- 모바일 세 조건에서 실제 터치로 확대 보드 이동, 회전 후 정렬, 전체 보기 복귀 확인
- 스코어보드와 다른 페이지를 포함한 실시간 검수 101개 통과

바닥 기준점 최대 오차 0.01042 CSS px
