# 모바일 원본 테마와 반응형 검수

2026-10-20 · 로컬 프로덕션 빌드 · PR #124

## 변경 기준

모바일에서 본문과 조작부를 읽을 수 있는 크기로 재배치하고 기존 화면의 재질·그림·장식을 사용

- KoTH: 원본 지도에서 제목, 왕관과 리본, 산, 라운드별 길과 번호, 카드, 테두리를 재사용
- 마이페이지·문제 상세: 큰 양피지 보드 안에 내용을 배치하고 원래의 금테와 목재 점수판을 유지
- 스코어보드: 원래 곡선 종이 테두리와 하단 명패를 유지하고 그래프는 화면 너비에 맞춤
- 순위표: 14개 열을 유지하고 표 영역에서만 가로 스크롤
- 규칙·동아리 부스: 기존 종이와 나무 재질, 장식, 그림을 유지
- 보드: 배경 한 장과 원판의 바닥 기준점을 맞추고 원래 금색 메뉴 아이콘을 사용

전체 페이지를 데스크톱 캔버스로 축소하던 공통 래퍼는 제거
양피지 무늬는 원본의 빈 부분을 반복하여 긴 내용에서도 세로로 늘어나지 않도록 처리
새 래스터 이미지·글꼴·런타임 의존성은 추가하지 않음

## 화면 크기와 배율

`scripts/qa-frontend-responsive.js`로 8개 경로 × 12개 조건, 총 96개 확인

경로: 보드, 스코어보드, KoTH, 마이페이지, 문제 상세, 규칙, 동아리 부스, 관리자

| 화면 크기 | DPR |
| --- | --- |
| 320×568, 390×844, 844×390 | 1 |
| 768×1024, 1024×768 | 1 |
| 1100×900, 1101×900 | 1 |
| 1440×900, 1920×1080, 1600×600 | 1 |
| 390×844, 1440×900 | 2 |

확인 항목:

- 화면 전체의 가로 넘침, 깨진 이미지, 렌더링 오류, 예상하지 못한 API 요청 없음
- 주사위 횟수 16px, 모바일 본문과 문제 제목 16px, 순위표와 범례 14px 이상
- 주요 모바일 메뉴와 조작부의 터치 영역 44px 이상
- KoTH 카드 6개, 라운드 장식 3개와 원본 산 그림 표시
- 스코어보드 14개 열 및 표 내부 가로 스크롤 유지
- 보드 배경 한 장, 원래 16:9 배경 비율, 바닥 기준점과 화면 끝 덮임 확인

## 기능과 긴 내용

`scripts/qa-frontend-interactions.js`에서 320·390·768·1440px의 90개 흐름 통과

- 열린 문제 목록·검색, 황금열쇠, 룰렛 결과, 기차 목적지 선택·취소, 문제 선택·닫기
- QR 발급, 플래그 제출 결과, 인스턴스 중지 확인창의 취소
- KoTH 문제 상세와 팀 토큰 열기·닫기
- 스코어보드 그래프 확대·복귀와 14개 열 가로 이동

긴 팀명·멤버명·문제 제목·본문을 넣어 5개 경로 × 320·390·768px, 총 15개 추가 확인
팀명과 멤버명은 줄바꿈하며, 마이페이지의 기록 없음 문구는 보이는 표 너비 안에 표시
긴 문제 제목이 추가되어도 KoTH 완료 도장은 카드 그림의 비율을 유지

## 데스크톱 구성 비교

1440×900에서 이전 원본 구성 캡처와 비교
KoTH·문제 상세·규칙·관리자는 픽셀 차이 없음
마이페이지·스코어보드·동아리 부스는 채널값 8을 넘는 픽셀 차이가 각각 0.061% 미만
보드는 요청된 상태판 가림 제거와 원판 비율 보정으로 차이가 있으며 36개 칸과 말·주사위 좌표를 별도 검수

## 실행과 증거

로컬 프리뷰 URL을 연 Playwright CLI 세션에서 실행

```powershell
npm test
npm run build
npx --offline --yes --package @playwright/cli playwright-cli -s=mobile-theme-responsive run-code --filename scripts/qa-frontend-responsive.js
npx --offline --yes --package @playwright/cli playwright-cli -s=mobile-theme-actions run-code --filename scripts/qa-frontend-live-layout.js
npx --offline --yes --package @playwright/cli playwright-cli -s=mobile-theme-actions run-code --filename scripts/qa-frontend-interactions.js
```

단위 테스트 515개 통과, 프로덕션 빌드 통과
기존 3D 청크의 500 kB 경고는 남아 있으며 이번 변경으로 새로운 라이브러리를 추가하지 않음

캡처와 수치는 Git 제외 경로 `output/playwright/mobile-theme`에 저장
`concept-responsive.json`, `live-final.json`, `interactions-final.json`, `rich-final.json`, `desktop-final-diff.json`에서 상세 수치 확인

브라우저 검수는 명시적인 로컬 API fixture와 고정된 시간 사용
실제 대회 데이터의 변경 또는 운영 API·운영 배포 검증을 의미하지 않음
실기기 Safari 검수와 브라우저 설정의 실제 확대·축소 조작은 이번 회차의 범위에 포함하지 않음
