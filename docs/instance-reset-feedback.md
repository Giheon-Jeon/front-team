# 초기화 실패 안내

문제 상세 조회에서 GET /teams/me/instances에 challenge_id를 함께 보냅니다
활성 인스턴스가 없으면 백엔드가 해당 문제의 마지막 본인 이력을 반환하므로 새로고침 후에도 실패 안내를 볼 수 있습니다

FAILED 상태의 delete_reason이 TTL_EXPIRED이면 사용 시간 만료를 안내합니다
replaced_instance_id가 있는 경우에는 초기화 도중 만료됐다고 표시합니다
사유가 없는 실패는 만료로 추측하지 않고 일반 실패 안내를 표시합니다
새 인스턴스를 생성하거나 상태가 바뀌면 이전 실패 안내는 사라집니다

초기화 확인창에는 남은 시간이 늘어나지 않으며 만료가 가까우면 먼저 연장하라는 안내를 추가했습니다
배포 순서는 스케줄러의 만료 사유 저장, 백엔드의 마지막 이력 조회, 프론트 안내 순서입니다
