# 프론트 성능 최적화와 QA

기준은 2026년 10월 20일 main의 7da1ad2 커밋

홍보·참가 안내는 전체 한글 글꼴 다운로드가 크고, 게임 화면은 배경·도장·패널 이미지가 큰 비중을 차지함
순위표·KoTH·마이페이지·관리자 대시보드는 탭을 숨겨도 30초마다 조회를 계속함
관리자 시계는 분 단위 표시를 위해 레이아웃 전체를 초마다 갱신하고 있었음

## 변경 내용

- 홍보 글꼴은 현재 문구와 날짜·숫자 표기에 필요한 434개 문자의 부분집합을 먼저 읽음
- 각 글꼴의 문자 윤곽과 advance width를 원본과 대조함
- 부분집합에 없는 문자는 기존 전체 글꼴을 읽도록 같은 family의 대체 face를 유지함
- 글꼴 생성 시 파일 해시를 URL에 붙여 재생성 후 캐시가 구버전을 사용하지 않도록 함
- 이미지 12개를 무손실 WebP로 바꾸고 RGBA 픽셀과 크기의 일치를 확인함
- 보드 배경만 해상도 1920×1080, 품질 96의 표시용 WebP를 별도로 만듦
- 보드 배경은 기존 WebP 2,675,276바이트에서 830,154바이트로 감소함
- 표시용 배경과 원본 PNG의 PSNR은 39.29dB이며 실제 보드 화면을 PC·모바일에서 비교함
- PNG 원본과 포스터 원본 새 창 링크는 유지함
- 동일한 관리자·참가자 배경 이미지는 같은 WebP URL을 사용함
- 반복 조회는 숨김 탭에서 예약을 멈추고 탭 복귀 시 바로 갱신함
- 진행 중인 요청과 탭 복귀가 겹치면 완료 후 한 번만 다시 읽음
- 관리자 시계는 별도 컴포넌트가 분 경계에서만 갱신하고 숨김 탭에서 예약을 멈춤

## 브라우저 측정

Vite 프로덕션 빌드를 Chromium에서 실행하고 동일한 로컬 API fixture로 비교함
PC는 1440×900, 모바일은 390×844 크기
아래 값은 화면 진입 시 Resource Timing의 decodedBodySize 합계이며 단위는 십진 MB
HTTP 압축 적용 후 전송량이나 실제 서비스의 LCP·INP를 뜻하지 않음
지도·외부 글꼴 등 교차 출처 리소스의 비공개 크기는 이 합계에 포함되지 않음

| 화면 | 크기 | 변경 전 | 변경 후 | 감소 |
|---|---|---:|---:|---:|
| 홍보 | PC | 2.338MB | 1.187MB | 49.2% |
| 홍보 | 모바일 | 2.034MB | 0.883MB | 56.6% |
| 참가 안내 | PC·모바일 | 1.886MB | 0.736MB | 61.0% |
| 보드 | PC·모바일 | 6.916MB | 5.071MB | 26.7% |
| KoTH | PC | 9.579MB | 7.228MB | 24.5% |
| KoTH | 모바일 | 13.108MB | 9.866MB | 24.7% |
| 관리자 대시보드 | PC·모바일 | 4.302MB | 3.412MB | 20.7% |

홍보·참가 안내에서 초기 글꼴 3개는 1,349,372바이트에서 188,708바이트로 86.0% 감소함
현재 문구에서는 부분집합만 요청하는 것을 확인했고, 별도의 새 한글 문자로 전체 글꼴 대체 요청도 확인함
무손실 변환한 12개 이미지의 파일 크기 합계는 27,130,964바이트에서 18,700,390바이트로 31.1% 감소함
이미지는 화면·선택 상태에 따라 읽으므로 이 합계 전체를 첫 진입 절감량으로 계산하지 않음

## QA 결과

- 기존 테스트 507개와 반복 조회 회귀 테스트 7개, 총 514개 통과
- 프로덕션 빌드와 git diff --check 통과
- 홍보, 참가 안내, 로그인, 보드, 순위표, KoTH, 마이페이지, 문제 상세, 규칙, 동아리 축제장, 관리자 대시보드의 PC·모바일 22개 조건 확인
- 22개 조건에서 JavaScript 런타임 예외, 깨진 이미지, 문서 가로 넘침, 화면 오류 안내가 없음
- 홍보·참가 안내의 PC·모바일 캡처는 기준 빌드와 픽셀 단위로 일치함
- 보드 배경 변경 후 보드판 위치·모바일 스크롤·주사위 표시를 캡처로 확인함
- 무손실 이미지의 RGBA 전체 바이트를 원본과 비교함
- 로컬 응답의 2·4 주사위를 한 번 굴린 뒤 WebGL 캔버스와 버튼 활성 복구를 확인함
- 홍보 진입에서는 3D·관리자·QR 코드를 요청하지 않음
- 글꼴 부분집합에 없는 한글을 요청하면 전체 글꼴을 읽음

탭 가시성 검사는 브라우저에서 document.hidden과 visibilitychange를 재현하고 Playwright 시계로 90초를 진행함
이 시계 검사는 다운로드 용량 측정과 별도 브라우저에서 수행함

| 화면 | 숨김 90초 요청 | 복귀 직후 조회 | 다음 30초 조회 | 화면 이탈 후 90초 조회 |
|---|---:|---:|---:|---:|
| 순위표 | 0 | 2 | 2 | 0 |
| KoTH 목록·내 팀 | 0 | 2 | 2 | 0 |
| 마이페이지 | 0 | 5 | 5 | 0 |
| 관리자 대시보드 | 0 | 4 | 4 | 0 |

단위 테스트에는 느린 요청 중 반복적인 탭 복귀, 숨김 상태에서 마운트, StrictMode 정리 직후 요청 방지, 실패 후 재개, 첫 관리자 조회 중복 방지도 포함됨

## 재현

Node 의존성은 lockfile 기준으로 설치하며 추가 런타임 의존성은 없음

```sh
npm ci
npm test
npm run build -- --manifest
npm exec vite preview -- --host 127.0.0.1 --port 4174 --strictPort
```

다른 터미널에서 output/playwright 폴더를 만든 뒤 실행
새 브라우저 세션을 사용하며 Resource Timing 측정 중 Playwright 시계는 설치하지 않음
화면 QA 스크립트는 API 응답을 로컬 fixture로 대체하고 실제 운영 서버를 검증하지 않음

```sh
npx --yes --package @playwright/cli playwright-cli -s=performance-qa open http://127.0.0.1:4174/ --headed
npx --yes --package @playwright/cli playwright-cli -s=performance-qa run-code --filename scripts/qa-frontend-performance.js
```

글꼴이나 원본 이미지를 수정했을 때만 자산을 재생성
Python 의존성은 자산 생성용이며 npm 빌드·CI에는 필요하지 않음

```sh
python -m pip install "fonttools[woff]" Pillow
python scripts/subset-intro-fonts.py
python scripts/optimize-game-images.py
```

캡처·측정 원본은 output/playwright에 보관하고 저장소에서는 제외함
전체 글꼴 대체 경로가 있어 문구 수정 시 생성 스크립트를 실행하지 않아도 문자는 표시되지만, 작은 글꼴 요청을 유지하려면 재생성이 필요함

## 측정 범위

실제 운영 API, 실기기, 배포 환경 네트워크 성능은 이번 로컬 QA의 범위 밖임
3D 공통 청크 684KB에 대한 기존 Vite 경고는 남아 있으며 gzip 기준 약 174KB이고 인증 후 보드 진입에서 읽음
이 변경에서는 주사위 모델·물리 동작과 게임 규칙을 유지함
