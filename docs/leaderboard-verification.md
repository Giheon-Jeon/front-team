# 리더보드 화면 확인

2026-09-20 로컬 확인
운영 API나 실제 대회 인스턴스는 호출하지 않음

## 화면과 조작

- 1280×720, 1440×1000, 1920×1080에서 순위표와 버튼의 프레임 이탈 없음
- 긴 한글과 영문 팀 이름은 자기 칸 안에서 말줄임
- 그래프 오른쪽 끝의 정보창이 그래프 영역 안에 남고 범례를 가리지 않음
- 8개 팀의 정보창 내용이 그래프 아래로 빠져나가지 않음
- 정방향과 역방향 드래그로 시간 구간 확대
- 더하기와 빼기 버튼으로 확대와 축소
- 전체 보기, 더블클릭, Escape로 초기 범위 복원
- 키보드의 더하기와 방향키로 확대와 점수 탐색
- 반복 확대 시 최대 범위를 벗어나지 않으며 짧은 시간 범위는 초 단위로 표시
- 그래프 조작으로 주변 글자가 선택되거나 기본 검은 포커스 테두리가 남지 않음
- 숫자 버튼과 이전·다음으로 18개 팀을 6개씩 이동
- 1·2·3등 장식은 해당 순위에만 표시하고 2페이지부터는 7위 이상 표시

## 로컬 실제 API 연결

격리된 PostgreSQL과 백엔드 main을 실행해 확인
프론트와 백엔드 소스 사이에 응답 모킹을 넣지 않고 HTTP로 연결

- 연동확인팀의 총점 825, KoTH 200, CLUB 425 표시
- 총점에 CLUB 점수를 중복 합산하지 않음
- 전체 순위에 signature_score가 없고 그래프에는 SIGNATURE 기록이 있는 현재 계약 확인
- 그래프에 없는 팀의 CLUB 점수는 0으로 추측하지 않고 하이픈 표시
- 수동 새로고침 시 순위와 그래프 API가 모두 200으로 응답
- 새로고침해도 선택한 확대 구간 유지
- 브라우저 오류와 경고 없음

## 남은 연결 조건

전체 팀의 CLUB 점수를 표시하려면 백엔드 순위 응답에 signature_score 필요
요청 내용은 [백엔드 요청사항](leaderboard-backend-request.md)에 별도 정리

57631 포트는 긴 이름과 3페이지를 확인하기 위한 명시적 개발용 데이터
57630 포트는 로컬 백엔드를 연결한 실제 API 확인용 화면
개발용 데이터는 운영 빌드나 API 오류의 대체 응답으로 사용하지 않음
운영 번들에서 긴 팀 이름을 포함한 검수용 데이터 문자열이 빠지는 것도 확인

검증은 로컬에서 진행했으며 운영 배포와 노션 수정은 검증 범위에 포함하지 않음

## 2026-10-20 모바일과 와이드 구성 통일 확인

운영 빌드를 로컬 미리보기 서버에서 실행하고 명시적인 8팀 API fixture로 검증
실제 운영 데이터나 계정은 수정하지 않음

- 320px 모바일부터 3840px 와이드까지 16개 화면 크기·DPR 조합에서 동일한 16:9 전경과 균일 배율 확인
- 제목, 그래프 축, 오른쪽 범례와 14열 순위표의 원본 좌표와 데이터 일치
- 별도 모바일 제목, 로그인 배경과 카드형 순위표가 표시되거나 다운로드되지 않음
- 전경 WebP 한 번과 풍경 WebP 한 번만 요청하며 원본 전경 파일은 변경하지 않음
- 확대 보기에서 원래 읽기 크기로 표시하고 표의 Rank부터 CLUB까지 가로 이동 가능
- 그래프에서 시작한 실제 터치 입력으로 가로·세로 이동하며 화면 맞춤으로 원상 복귀
- 세로·가로 회전 시 읽기 상태 유지, 데스크톱 너비로 복귀 시 전체 화면 맞춤
- 6회 연속 화면 크기 변경 후에도 그래프 축과 종이 프레임 정렬 유지
- 데스크톱·모바일에서 그래프 확대·초기화·키보드 탐색·드래그, 순위 페이지 이동·새로고침 통과
- 빈 결과와 API 오류 상태를 두 화면에서 확인하고 브라우저 실행 오류 없음
- 리더보드·KoTH·관리자·보드의 반응형 화면 32개 확인, 전체 자동 테스트 514개 통과

이 검증은 PR 수정본의 로컬 결과이며 운영 배포 완료를 의미하지 않음
